Compatibility requirements

Requires Android 12–16 with the exact four-file AOSP und-Arab compact/elegant layout, KernelSU Next, a compatible systemless mount provider, and a reboot after applying. Custom import additionally requires Manager v3.1.0+.

No network, telemetry, daemon, font hook, or physical system write.
